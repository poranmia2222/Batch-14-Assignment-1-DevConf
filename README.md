## 📸 Project Overview

**DevConf 2026** is a conference landing page designed to showcase information about a technology conference, including speakers, ticket plans, event details, and registration options.

The project focuses on creating a clean, modern, and responsive user interface using only HTML and CSS.

---

## ✨ Features


- 🧭 Navigation bar
- 🎯 Hero section with call-to-action
- 🎤 Speaker section
- 💳 Ticket/pricing section
- 📋 Registration call-to-action
- 🦶 Footer section
- 🎨 Clean and modern UI
- 📐 CSS Flexbox and Grid

---

## 🛠️ Technologies Used

- HTML5

- CSS Flexbox

- Responsive Web Design
